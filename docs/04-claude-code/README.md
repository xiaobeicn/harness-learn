Claude Code 的核心实现并非完整开源，因此本阶段会明确区分官方文档、可观察实验和推测，不把黑盒行为伪装成源码结论。

## 阶段目标

- [ ] 理解项目指令、技能、会话上下文和长期记忆的边界。
- [ ] 通过实验观察上下文压缩前后的信息保留情况。
- [ ] 理解子 Agent 的上下文隔离、任务委派和结果回传。
- [ ] 比较单 Agent 工具调用与 Multi-Agent 编排的成本和收益。
- [ ] 总结四个 Harness 的设计取舍。

## 重点问题

- 哪些上下文是自动发现、显式注入或运行时生成的？
- Memory 保存什么，不应该保存什么？
- 子 Agent 是真正独立的 Runtime，还是同一会话的受限分支？
- 多 Agent 在什么任务上有收益，什么任务上只会增加协调成本？

开始本阶段时优先使用官方文档和可重复实验建立课程，不预先推测内部实现。
